# Onboard Tour 1.9.1

Fixes mouse access to the tour launcher and editor in compact 1×1 Qlik objects. Narrow objects show a help icon with an accessible label, use the available cell space, and keep Qlik hover controls from covering the button. Larger objects retain their configured appearance.

Adds responsive sizing/cleanup regression tests. Validated mouse launch, editor access, save/reopen, checklist dismissal, and keyboard launch/navigation in the Adaptive Qlik Cloud test app.

Download **onboard-qs.zip** below and replace the existing **onboard-qs** extension in Qlik Cloud Administration. Existing tours and settings are preserved.

This is guided practice; steps do not automatically verify task completion. Client-managed Qlik Sense, mobile, and screen-reader acceptance are not certified by this release.
